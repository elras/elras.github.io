# Source Sans 3

Source Sans 3 is designed by Adobe and licensed under the SIL Open Font License
1.1; the copyright notice and license are included in `OFL.txt`.

These Latin-subset WOFF2 files were downloaded from Google Fonts (v20):

- [Normal, variable weights 400–700](https://fonts.gstatic.com/s/sourcesans3/v20/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2)
- [Italic, weight 400](https://fonts.gstatic.com/s/sourcesans3/v20/nwpDtKy2OAdR1K-IwhWudF-R3woAa8opPOrG97lwqLlOxCkSmg.woff2)

The site serves them locally through `styles.css`, with `font-display: swap` and
Arial/sans-serif fallbacks. No Google Fonts request or build step is needed.
